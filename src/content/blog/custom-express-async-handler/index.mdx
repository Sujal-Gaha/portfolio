Writing `try-catch` blocks inside every route handler gets repetitive fast. While packages like `express-async-handler` exist, you do not need an external dependency for something that takes five lines of TypeScript.

## 1. The Async Handler

Create an `async-handler.ts` file:

```typescript
import { Request, Response, NextFunction } from 'express'

type AsyncRequestHandler = (
  req: Request,
  res: Response,
  next: NextFunction,
) => Promise<any>

export const asyncHandler =
  (fn: AsyncRequestHandler) =>
  (req: Request, res: Response, next: NextFunction) => {
    Promise.resolve(fn(req, res, next)).catch(next)
  }
```

## 2. How It Works

- **Higher-order function:** `asyncHandler` takes an async route function `fn` and returns a standard Express middleware function `(req, res, next)`.
- **Catching rejections:** Wrapping `fn(req, res, next)` in `Promise.resolve()` ensures that even if a synchronous error is thrown, it is treated as a promise rejection.
- **Forwarding to Express:** Any rejected promise is passed straight into `next(error)`, handing it off to your centralized Express error-handling middleware.

## 3. Comparison

### Before: Repetitive try-catch in every controller

```typescript
const getAllProducts = async (req: Request, res: Response, next: NextFunction) => {
  try {
    const products = await ProductModel.find({}).limit(20)

    res.status(200).json({
      status: 200,
      data: products,
      success: true,
      message: 'Fetched products successfully',
    })
  } catch (error) {
    next(error)
  }
}
```

### After: Clean controller with asyncHandler

```typescript
const getAllProducts = asyncHandler(async (req: Request, res: Response) => {
  const products = await ProductModel.find({}).limit(20)

  res.status(200).json({
    status: 200,
    data: products,
    success: true,
    message: 'Fetched products successfully',
  })
})
```

Wrapping handlers with `asyncHandler` keeps controllers focused on the request logic, keeps error routing consistent, and adheres to DRY without pulling in extra dependencies.
